# 💪 LifTiers

## Open-Source Lifting Tracker — Built for Strength, Powered by Community

LifTiers is a modern, open-source workout tracking application designed for lifters who want complete control over their training data. Built with performance and developer experience in mind, it combines the best of Astro's island architecture with React's interactivity.

### 🔥 Why LifTiers?

- **📊 Track Everything**: Log sets, reps, weight, RIR (Reps in Reserve), and advanced techniques like rest-pause and partials
- **🏆 Personal Records**: Automatic PR detection with Epley formula and volume scoring
- **📋 Routine Management**: Create, edit, and execute custom workout routines
- **📱 Full Responsive**: Train anywhere — from your phone, tablet, or desktop
- **🔒 Privacy First**: All data stays in your browser with Zustand + localStorage — no cloud required
- **⚡ Real-time Progress**: Visual feedback, PR banners, and performance metrics

### 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| **Astro** | Fast, islands-based frontend framework |
| **React** | Interactive components for workout logging |
| **Zustand** | Simple, scalable state management with persistence |
| **TypeScript** | Type-safe development |
| **Tailwind CSS** | Utility-first styling, fully responsive |
| **DeepSeek-Coder** 🤖 | AI-powered coding assistant during development |

### 🧠 Advanced Features

- **Epley Formula**: Intelligent PR comparison across different weight/reps combinations
- **Volume Scoring**: Compare 80kg×1 vs 68kg×7 objectively
- **RIR Tracking**: Log Reps in Reserve for autoregulation
- **Extra Techniques**: Rest-pause, partial reps, and advanced lifting methods
- **Workout History**: Complete training log with all previous sessions
